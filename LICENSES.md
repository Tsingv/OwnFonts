# Licensing and upstream projects

This repository contains build scripts and metadata. Generated font files remain
subject to the licenses of their upstream fonts and the icon sets included by
Nerd Fonts.

Upstream projects:

- Sarasa Gothic: https://github.com/be5invis/Sarasa-Gothic
- LXGW WenKai GB: https://github.com/lxgw/LxgwWenkaiGB
- LXGW Neo XiHei: https://github.com/lxgw/LxgwNeoXiHei
- Nerd Fonts: https://github.com/ryanoasis/nerd-fonts

Before redistributing a generated font, consult the license files and notices in
the corresponding upstream release/repository. The CI does not relicense any
font or glyph.
